# Resurse și dovezi ale proiectului

Acest folder păstrează materiale folosite sau create de echipă pentru proiect: brainstorming, capturi de test, exemple și alte dovezi de contribuție. Fiecare subfolder trebuie să aibă un README cu sursa, contextul, data aproximativă și eventualele limite de utilizare. Păstrați materialele private și cheile API în afara Git.

- [Sesiunea Discord de brainstorming](sesiune%20discord%20brainstorming.png): whiteboard-ul organizat de echipă înaintea implementării.
- [ai-fail-2](ai-fail-2/README.md): cinci capturi oferite de Flavius, care documentează un rezultat insuficient pentru PDF-ul C++ de 127 de pagini.
